# CSS 书写

## 1 Svelte 样式书写方式

### 1.1 style 标签

在 style 标签内可以直接书写样式：

```html
<style>
  div {
    color: burlywood;
  }
</style>
```

每个组件都只有一个顶层 `<style>` 标签。

`<style>` 标签也可以嵌套在其他元素或逻辑块中，此时该标签将会按原样式插入 DOM：

```html
<style>
  div {
    color: red; // 会被插入 div 元素中
  }
</style>
```

### 1.2 style: 行业样式简写

```html
<div style:color="red">...</div>
<div style="color: red;">...</div>
<div style:color="{myColor}">...</div>
<div style:color>...</div>
<div style:color style:width="12rem" style:background-color={darkMode ? 'black' : 'white'}>...</div>
<div style:color|important="red">...</div>
<!-- 自定义属性 -->
<div style:--columns={columns}>...</div>
```

指令与样式属性结合时，指令将优先于重要属性：

```css
<div style:color="red" style="color: blue">This will be red</div>
<div style:color="red" style="color: blue !important">This will still be red</div>
```

## 2 :global全局样式

### 2.1 应用级全局样式

```css
// 所有 div  p 元素 样式，内部
 :global {
  div {  }
  p {
    .list{

    }
   }
 }

 .a :global {
  /* applies to every `.b .c .d` element, in any component,
     that is inside an `.a` element in this component */
  .b .c .d {...}
 }
```

### 2.2 元素级全局样式

```css
// 应用到 body 标签
:global(body) {
  margin: 0;
}

// 应用到组件内 div 元素下的所有 strong 标签
div :global(strong) {
  /* applies to all <strong> elements, in any component,
     that are inside <div> elements belonging
     to this component */
  color: goldenrod;
}

// 应用到组件内 p 元素下的所有 `class="big red"`
p:global(.big.red) {
}
```

### 2.3 帧动画全局样式

如果需要将 `@keyframes` 全局化，需要在 keyframes 加前缀 `-global-`，这个前缀会在编译后移除：

```css
@keyframes -global-my-animation-name {
}
```

## 3 自定义属性

### 3.1 自定义属性写法

定义自定义属性：

```css
<Slider
 bind:value
 min={0}
 max={100}
 --track-color="black"
 --thumb-color="rgb({r} {g} {b})"
/>
```

使用自定义属性：

```css
<style>
 .track {
  background: var(--track-color, #aaa);
 }

 .thumb {
  background: var(--thumb-color, blue);
 }
</style>
```

上述自定义属性本质是下面代码的语法糖：

```css
<svelte-css-wrapper style="display: contents; --track-color: black; --thumb-color: rgb({r} {g} {b})">
 <Slider
  bind:value
  min={0}
  max={100}
 />
</svelte-css-wrapper>
```

### 3.2 SVG 自定义属性

SVG 中使用自定义属性方式：

```css
<g style="--track-color: black; --thumb-color: rgb({r} {g} {b})">
 <Slider
  bind:value
  min={0}
  max={100}
 />
</g>
```
