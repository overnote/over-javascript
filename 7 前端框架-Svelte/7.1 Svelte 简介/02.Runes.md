# 02-Runes

## 02.1 $state 状态管理

### 02.1.1 $state 基本使用

`$state` 用来创建一个响应式数据，如果是一个引用类型则产生一个 proxy 对象：

```svelte
<script lang="ts">
const count = $state(1)
const obj = $state<{ num: number }>({ num: 1 }) // obj 为 Proxy

const handler = () => count++
</script>

<button onClick={ handler }>{ count } </button>
```

不能直接对 class 类使用 `$state`，但是可以对其成员使用：

```svelte
<script lang="ts">
class Demo {
  num: number = $state(0)
  txt: string = $state('')
  constructor(txt: string) {
    this.txt = txt
  }

  public add() {
    this.num++
  }
}

const d = new Demo('hi')
</script>

<button onclick={() => d.add()}>+</button>
<p>{d.txt} {d.num}</p>
```

### 02.2.2 $state.raw 浅监听

`$state.raw` 可以无需深度监听数组与对象中的数据变化，以提升大数据对象的使用性能：

```js
const person = $state.raw({
  name: 'Heraclitus',
  age: 49,
})

// 不会 effect
person.age += 1

// 创建了新对象，会 effect
person = {
  name: 'Heraclitus',
  age: 50,
}
```

### 02.2.3 $state.snapshot 快照

在 `$state` 进行深度监听数据时，返回的是一个Proxy对象，如果要在某一个时间片段中获取该Proxy对象的静态数据，可以使用$state.snapshot：

```js
const demo = $state({ a: 1, b: 2 })
console.log('快照 1', $state.snapshot(demo)) // { a: 1, b: 2 }
demo.a = 4
console.log('快照 2', $state.snapshot(demo)) // { a: 4, b: 2 }
```

## 02.2 $derived 计算属性

### 02.2.1 $derived 基本使用

`$derived` 类似 Vue 的computed和 React 的useMemo，用来监听已有的 state 变化返回代码处理后的数据：

```js
let num = $state(1)
let multiple = $derived(num * 2)
```

利用 `$derived.by` 则可以处理复杂数据：

```js
let arr = $state([1, 2, 3, 4])
let total = $derived.by(() => arr.reduce((a, b) => a + b, 0))
```

## 02.3 $effect 状态追踪

### 02.3.1 $effect 基本使用

`$effect` 函数可以追踪 state 和 derived 变化，重新执行包装的函数。在 Svelete 中，其实数据的响应式的副作用就是通过 Svelte 内置的 effect 函数实现的。自定义 effect 函数方式如下：

```js
let num = $state(0)

$effect(() => {
  console.log('num changed:', num)
})
```

`$effect` 只能监听函数内同步读取的依赖，异步读取的数据不会被追踪，例如 await 和 setTimeout 中的数据：

```js
let testNum = $state(0)
let testDerive = $state(0)

$effect(() => {
  setTimeout(() => {
    testDerive = testNum * 2 // testDerive 位于异步函数中，不会被追踪
  }, 0)
})
```

### 02.3.2 $effect.pre 预调用

`$effect.pre` 会在 DOM 更新前调用包装的函数。

### 02.3.3 $effect.tracking 查看是否被追踪

`$effect.tracking()` 函数会返回一个布尔值，可以查看当前组件是否存在追踪上下文

### 02.3.4 $effect.root

`$effect.root` 可以创建一个不被追踪、不会被自动清理的区域，如果需要手动控制嵌套 `$effect` 很有用：

```js
let count = $state(0)

const cleanup = $effect.root(() => {
  $effect(() => {
    console.log(count)
  })

  return () => {
    console.log('effect root cleanup')
  }
})
```

## 02.4 父子通信 $props $bindable $host

### 02.4.1 `$props` 父传子

```js
const { test }: { test: string } = $props()
```

### 02.4.2 `$bindable` 子传父

```html
<!-- 子组件 -->
<script>
  let { test = $bindable() }: { test: string } = $props()
</script>
<input bind:value="{test}" />

<!-- 父组件 -->
<script>
  import Child from './child.svelte'
  let label = $state('Hello')
</script>

<Child bind:test="{label}" />
<p>{label}</p>
```

### 02.4.3 $host 调用父组件函数

`$host`支持调用父组件函数

```js
// 子组件
<svelte:options customElement="my-test" />
<script lang="ts">
  function dispatch(type: string) {
    $host().dispatchEvent(new CustomEvent(type))
  }
</script>

<button onclick="{()" ="">dispatch('decrement')}>decrement</button>
<button onclick="{()" ="">dispatch('increment')}>increment</button>


// 父组件
<script lang="ts">
  import 'son.svelte'
  let count = $state(0)
</script>
<my-test
  ondecrement={() => count -= 1}
  onincrement={() => count += 1} ></my-test
>
<p>count: {count}</p>
```

贴士：

- 要使用customElement需要在vite中加上 `customElement:true`

```json
compilerOptions: {
    customElement: true
    }
```

- 子组件中的customElement命名必须带有-，例如 my-comp。

## 02.5 开发套件 $inspect 日志

### 02.5.1 $inspect 基本使用

`$inspect` 用于打印 state 和 derived 数据变化，当状态和计算属性发生变化时，打印数据：

```js
let count = $state(0)
let num = $derived(count * 2)
$inspect(num)
```

### 02.5.2 $inspect(...).with

`$inspect(...).with` 则可以自定义 debug 方法：

```js
let count = $state(0)
let num = $derived(count * 2)

$inspect(num).with((type, value) => {
  console.log('custom:', type, value)
})
```
