# 01-Svelte概览

## 一 Svelte 简介

Svelte的前身是发布于2013年的Ractive.js，后者几乎与React同时问世，其灵感来自于 Knockout 和 Angular。2016 年，作者 Rich Harris（ 同时也是 rollup 作者） 在 Ractive.js 落地实践后，发现其存在一定的局限性，诞生了使用编译手段解决现代Web 开发痛点的想法，Svelte的第一个版本，就是在Reactive基础上添加一个编译器。

截止 2026 年十年磨砺，已经相对成熟，目前官方也配套开源了 SvelteKit SSR 框架，开箱即用。

Svelte 与 目前阶段的 Vue、React 最大的不同是：抛弃了 虚拟 DOM，采用编译方式实现数据响应式。Svelte 把运行期间的事情提前到了编译阶段完成，所以该框架生成的代码 0 运行时，体积很小（18kb 左右）。比如：对于响应式数据，React 需要在运行时收集依赖，会增加代码运行耗时，而Svelte 在编译阶段会提前计算好某个变量的引用位置，更新 DOM 时机，生成具体的 DOM 更新指令，运行时通过对变量进行脏标记更新 DOM 视图。

Svelte 编译过程：

- 1、将 .svelte 文件解析为抽象语法树（AST）
- 2、分析 AST 中模板绑定关系、状态、事件等，生成操作 DOM 的 JS 代码

## 二 Svelte基本使用

Svelte与Vue类似，需要创建后缀为 .svelte 的文件，内容为：

```vue
<script module lang="ts"></script>

<script lang="ts"></script>

<style></style>
```

Svelte5 之后，文件内引入了一个特殊符号，如 `$state` 、 `$effect`，称之为 **Runes**，类似于 React 中的 useState、useEffect。后续章节将会详细解释。
