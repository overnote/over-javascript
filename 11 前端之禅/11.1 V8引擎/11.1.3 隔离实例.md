# 隔离实例

## 1.1 V8 引擎隔离实例 Isolate

V8 引擎的实例全称为：隔离实例（Isolated Instance）。每个实例内部都拥有完全独立的状态，如：堆管理、垃圾回收等。

可以创建多个 Isolate 实例，实例本身不执行 JavaScript，也没有 JavaScript 环境对应的上下文。在 Nodejs 中， V8 由于内置，且 Node 需要使用 V8，所以已经存在了这样的一个实例，可以直接使用：

```c++
void Method(const v9::FunctionCallbackInfo<v8::Value> & args){
    Isolate* isolate = args.GetIsolate();
}
```

## 1.2 上下文 Context

通过隔离实例可以获取到 JavaScript 执行环境的上下文对象：

```c++
v8::Isolate* isolate = v8::Isolate::New();
v8::Local<v8::Context> context = v8::Context:;New(isolate);
```

## 1.3 脚本 Script

脚本即一段编译好的 JS 代码，可以在 V8 中执行：

```c++
v8::Local<v8::String> source = "console.log('hello world')";
// 绑定上下文并编译
v8::Local<v8::Value> result = v8::Script::Compile(context, source).ToLocalChecked();
// 执行脚本
v8::Local<v8::Value> result = script->Run(context).ToLocalChecked();
```
