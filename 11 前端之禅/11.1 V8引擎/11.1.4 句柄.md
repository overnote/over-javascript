# 1 句柄

## 1.1 句柄概念

V8 在GC 时，通常会将 JavaScript 对象移来移去，若用指针来操作对象，一旦对象被移走，就会产生野指针。为了解决这个问题，引入了句柄：

> 句柄: V8 堆内存中 JavaScript 数据对象的一个引用。

GC中对象的移动的同时，垃圾回收器也会更新引用了这个数据块的句柄，保证其不会切断联系。如果一个对象不再被句柄引用，则会被认为是垃圾，V8 会不时的对齐执行回收。

V8 种的句柄有多种：

- 本地句柄：`v8::Local`
- 持久句柄：`v8::Persistent`
- 永生句柄：`v8::Eternal`
- 待实本地句柄
- 其他句柄

V8 中的句柄由C++中的句柄（模板类）来实现，根据不同的 V8 数据类型进行不同的声明，如：`v8::Local<v8::Number>`。这些句柄类，都可以通过 点语法操作句柄对象的方法，此外还重载了 `*`、`->` 操作重复，即可以通过这些操作符获取到数据对象的实体指针。

## 1.2 常见句柄

### 1.2.1 本地句柄 Local

本地句柄位于栈内存，在对应的析构函数被调用时删除，其生命周期由其所在的句柄作用域（Handle Scope）决定。

常见本地句柄 API 有：

```c++
// 创建 New （静态方法）
Local<T>::New(Isolate* isolate, Local<T> that);     // 传入 isolate 实例、另外一个本地句柄，进行复制构造（T 代表 JS 数据类型）
Local<T>::New(Isolate* isolate, const PersistentBase<T> &that); // 传入 Isolate 实例和一个持久句柄

// 推荐使用 JavaScript 的静态方法获取本地句柄
Local<Number> Number::New(Isolate* isolate, double value);

// 清除 Clear：将一个句柄设置为空句柄，使用 IsEmpty 函数判断是否为空
Local<Number> handle = Number::New(isolate, 233);
handle.Clear();
if(handle.IsEmpty()){}  // 操作空句柄会导致程序崩溃

// 数据类型转换 As、Cast
Local<Number> ret1 = Local<Number>::Cast(handle);
Local<Number> ret2 = handle.As<Number>();
```
