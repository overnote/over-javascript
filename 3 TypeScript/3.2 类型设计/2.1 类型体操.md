# 类型体操

## 1 类型的联合与交叉

### 1.1 联合类型

并集或符号：

```ts
let obj: { name: string } | { age: number }

obj = { name: 'lisi' }
```

### 1.2 交叉类型

交集与符号：

```ts
let obj: { name: string } & { age: number }

obj = { name: 'lisi', age: 30 }
```

这 2 个符号经常作用于多个类组成的类型，如：

```js
class A {}
class B {}
let obj: A & B // obj 中需要有 A 与 B 的成员
```

## 2 类型别名

使用 type 关键字可以给类型起个别名，可以让业务信息更清晰，减少一些重复代码：

```ts
type Age = number
let a: Age = 3
```

type 支持或、与操作：

```ts
class A {}
class B {}

type Cus = A & B

let cusInstance: Cus
```

贴士：使用类型别名的地方都可以替换为源类型，程序不会受到影响。

不过要注意的是：同一个别名不能声明两次，且类型别名的定义和普通变量存在一样的作用域限制。

## 3 类型嵌入

比如一个复杂的嵌套类型：

```ts
type APIRes = {
  user: {
    userId: string
    friendList: {
      count: number
      friends: {
        first: string
        last: string
      }[]
    }
  }
}
```

我们想直接获取 friendList 类型，也可以通过索引方式：

```ts
type FriendList = APIRes['user']['friendList']
```

任何结构对象、数组都可以采用这种键入方式获取类型。

## 4 keyof运算符

keyof 运算符可以获取对象的所有键：

```ts
type APIKeys = keyof APIRes // 'user'
```

把 keyof 和键入 结合使用，可以读取对象指定键的值：

```ts
function get<O extends object, K extends keyof O>(o: O, k: K): O[K] {
  return o[k]
}
```

如下所示的一个类，可以采用 key 优雅体现：

```ts
interface Person {
  name: string
  age: number
}

class Teacher {
  constructor(private info: Person) {}
  getInfo(key: string) {
    // return this.info[key]
    // 上述写法有有语法错误提示，需要使用类型保护
    if (key === 'name' || key === 'age') {
      return this.info[key]
    }
  }
}

// 更优雅写法：`T extends name` 等价于 `type T = name`
class Teacher {
  constructor(private info: Person) {}
  getInfo<T extends keyof Person>(key: T): Person[T] {}
}
```

## 5 TS 内置映射类型

TS 也内置一些 Utility Types：

- `Record<Keys, Values>`：键的类型为 Keys，值的类型为 Values 的对象
- `Partial<Object>`：把 Object 中每个字段都标记为可选的
- `Required<Object>`：把 Object 中每个字段都标记为必须的
- `Readonly<Object>`：把 Object 中每个字段都标记为只读的
- `Pick<Object, Keys>`：返回 Object 的子类型，只含指定 Keys

TS 内置的 Record 类型用于描述有映射关系的对象。用 Record 构建一个映射，将一周的每一天映射到次日：

```ts
type WeekDay = 'Mon' | 'Tue' | 'Wed' | 'Thu' | 'Fri'
type Day = WeekDay | 'Sat' | 'Sun'

// 使用Record方式
let nextDay1: Record<WeekDay, Day> = {
  Mon: 'Tue',
  Tue: 'Wed',
  Wed: 'Thu',
  Thu: 'Fri',
  Fri: 'Sat',
}
```

## 6 映射类型

Record 的示例也可以使用映射方式，这是Record的实现本质：

```ts
let nextDay2: { [K in WeekDay]: Day } = {
  Mon: 'Tue',
  Tue: 'Wed',
  Wed: 'Thu',
  Thu: 'Fri',
  Fri: 'Sat',
}
```

映射类型的功能更加强大，结合键入，可以约束特定键的值是什么类型！下面的示例中定义了多个类型与 Account 类型做映射，并额外处理其属性：

```ts
type Account = {
  id: number
  isEmployee: boolean
  notes: string[]
}

// 所有字段可选
type AccountOptional = {
  [K in keyof Account]?: Account[K]
}

// 所有字段都可为 null
type AccountNullable = {
  [K in keyof Account]?: Account[K] | null
}

// 所有字段只读
type AccountReadonly = {
  readonly [K in keyof Account]?: Account[K]
}

// 所有字段可写（等同于 Account）
type Account2 = {
  -readonly [K in keyof AccountReadonly]?: Account[K]
}

// 所有字段必须（等同于 Account）
type Account3 = {
  [K in keyof AccountOptional]-?: Account[K]
}
```

## 7 is 运算符

下列定义的函数内部报错：

```ts
function isString(value: unknown): boolean {
  return typeof value === 'string'
}

function parseInput(input: string | number) {
  let formattedInput: string
  if (isString(input)) {
    formattedInput = input.toUpperCase() // 类型“string | number”上不存在属性“toUpperCase”。
  }
}
```

由于 parseInput 函数当前作用域内，input 的类型是无法被isString真正细化为 string的，可以采用 TS 内置的类型防护措施：

```ts
function isString(value: unknown): a is string {
  return typeof value === 'string'
}
```
