# 05.Svelte 特殊元素

## 05.1 常见特殊元素

### 05.1.1 svelte:boundary 错误边界

`<svelte:boundary>` 可以处理错误边界，防止程序崩溃：

```html
<script lang="ts">
  import { onMount } from 'svelte'
  const resetFunc = $state()
  function handleError(error: string, reset: Function) {
    console.log(error)
    resetFunc = reset
  }
</script>

<svelte:boundary onerror="{handleError}">
  <p>Oops, Something went wrong.</p>
</svelte:boundary>

{#if resetFunc !== null}
<button onclick="{resetFunc}">Reset</button>
{/if}
```

### 05.1.2 svelte事件绑定

```html
<script lang="ts">
  function onkeydown(e: KeyboardEvent) {
    console.log(e.keyCode)
  }
</script>

<svelte:window {onkeydown}></svelte:window>
```

同理：`<svelte:document> <svelte:body> <svelte:head>` 可以支持在这些元素上绑定事件。

### 05.1.3 svelte:element

`svelte:element` 用于渲染不同场景下不确定的HTML标签：

```js
<script lang="ts">
  let isH1 = $state(true)
  let current = $derived(isH1 ? "h1" : "hr")
</script>

<svelte:element this={current}>
  This is a text.
</svelte:element>

<button onclick={() => isH1 = !isH1}>change</button>
```

### 05.1.4 svelte:option 改变组件配置

`<svelte:option>` 提供一个位置来改变每个组件的配置，例如是否允许runes, 定于当前组件的namespace和customElement等。常见 option 有：

- `<svelte:option runes={true}>`， 是否允许当前组件使用runes
- `<svelte:option namespace="test">`
- `<svelte:option customElement="my-element">`
- `<svelte:option css="inject">`, 启用改选项会将所有css以内联的方式写
