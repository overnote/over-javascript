# 07.生命周期

## 07.1 Svelte生命周期简介

svelte认为state的更新与全局组件无关，因此组件的生命周期没有before update和after update的部分，只有创建（onMount）和销毁（onDestroy）：

```ts
import { onMount, onDestory } from 'svelte'

onMount(() => {
  console.log('The component is mounted!')
})

onDestory(() => {
  console.log('The component is being destry')
})
```

贴士：beforeUpdate / afterUpdate 已经在 V5 版本废弃了。

## 07.2 tick

tick 它返回一个Promise，任何state改变后，会触发其resolve，或在下一个微任务触发resolve：

```ts
import { tick } from 'svelte'

$effect.pre(() => {
  console.log('组件更新')
  tick().then(() => {
    console.log('组件更新了')
  })
})
```
