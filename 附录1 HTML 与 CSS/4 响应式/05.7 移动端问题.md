## touch-action

由于要避免点击行为和手机双击行为发生冲突，click事件在移动端有300 ms延时，如果要取消这个延时可以使用下面的 css：

```css
html {
  touch-action: manipulation;
}
```

touch-action:manipulation表示浏览器只允许进行滚动和持续缩放操作，所以类似双击缩放这种非标准操作就不被允许，那么 click 事件的 300ms 延时就不存在了。

touch-action:none 可以解决移动端滑动页面时， touchmove 事件的监听错误：

```css
/* 
document.addEventListener('touchmove', function (event) {
event.preventDefault();
}); 
*/
html {
  touch-action: none;
  overflow: hidden;
}
body {
  touch-action: auto;
  height: 100vh;
  position: relative;
  overflow: auto;
}
```

不过，此方法改变了默认的滚动行为，比较适合原本就需要对默认滚动行为进行重置的单页，而对于传统的网页，通过传递passive:false参数解决：

```js
document.addEventListener(
  'touchmove',
  function (event) {
    event.preventDefault()
  },
  {
    passive: false,
  },
)
```

## image-set

image-set()函数可以根据不同设备的屏幕密度或者分辨率来显示不同的背景图（background- image）或者遮罩图片（mask-image）等

```css
.example {
  background-image: image-set(
    url(1.jpg) 1x,
    url(1-2x.jpg) 2x,
    url(1-print.jpg) 600dpi
  );
}
```

如果屏幕是1倍屏，也就是设备像素比是1∶1的话，就使用1.jpg作为背景图；如果屏幕是2倍屏及以上，就使用1-2x.jpg作为背景图；如果设备的分辨率大于600dpi，就使用1-print.jpg作为背景图。

dpi表示每英寸点数。通常屏幕每英寸包含72点或96点，打印文档的dpi要大得多，一般dpi值在600以上，我们就可以认为是打印设备了。1x、2x中的x其实是dppx的别称，表示每像素单位的点数，
也可以理解为屏幕密度。
