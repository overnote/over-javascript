# 渐变

线性渐变：从某一个位置开始向特定方向渐变。
径向渐变：从某一个位置开始向四周渐变。

注意：**渐变的本质就是背景图片，渐变本身不会影响元素的大小**。

## 1 线性渐变

### 1.1 线性渐变示例

线性渐变是从元素的一端开始，沿着直线过渡到另一端。linear-gradient 函数可以生成线性渐变图片：

```css
// 默认向下渐变：红色变为绿色
background: linear-gradient(red, green);

// 向左渐变：从右边红色渐变到左边绿色
 background: linear-gradient(to left, red, green);

// 向左上角渐变：从右下角红色渐变为左上角绿色
background: linear-gradient(to left top, red, green);

// 向右渐变：从左边红色渐变为右边绿色
background: linear-gradient(to right, red, green);
```

linear-gradient 函数使用三个参数来定义行为：角度、起始颜色、终止颜色。

颜色可以是 red、hex（ #0000ff）、 RGB（ rgb(0, 0, 255)）或者 transparent等关键字。

角度可以使用更确切的单位（比如度）。值 0deg 代表垂直向上（相当于 to top），更大的值会沿着顺时针变化，因此 90deg 代表向右渐变（相当于 to right）， 180deg 代表向下渐变，360deg 又会代表向上渐变：

```css
background-image: linear-gradient(90deg, white, blue);
```

还有一些其他单位可以用来表示角度，如下所示：

- rad—：弧度（ radian）。一个完整的圆是 2π，大概是 6.2832 弧度。
- turn：代表环绕圆周的圈数。一圈相当于 360 度（ 360deg）。可以使用小数来表示不足一圈，比如 0.25turn 相当于 90deg。
- grad：百分度（ gradian）。一个完整的圆是 400 百分度（ 400grad）， 100grad 相当于 90deg。

### 1.2 使用多个颜色节点

大部分渐变只需要两个颜色，即从一个颜色过渡到另一个。不过渐变也可以定义多个颜色的渐变，其中每个颜色可以称为一个颜色节点（ color stop）。

节点之间通过逗号分隔，渐变会自动均匀地平铺这些颜色节点。在本例中，最左侧（ 0%）从红色开始，过渡到中间（ 50%）的白色，到最右侧的蓝色（ 100%）。我们也可以在渐变函数中为每个颜色节点明确指定位置。例子代码等价于：

```css
background-: linear-gradient(90deg, red 0%, white 50%, blue 100%);
```

贴士：如果不给出百分比，则自动平分。

### 1.3 锐利的线性渐变

2 个色彩值之间，系统会自动计算插值，要获得锐利的渐变效果，就需要在同一个停止位置写 2 个色值，它们之间没有插值：

```css
background-image: linear-gradient(
  to,
  right,
  orangered 10%,
  orange 10%,
  orange 20%,
  gold 20%,
  gold 30%,
  lightgreen 30%,
  lightgreen 40%,
  cyan 40%
);
```

### 1.4 条纹

如果在同一个位置设置两个颜色节点，那么渐变会直接从一个颜色变换到另一个，而不是平滑过渡：

```css
background-image: linear-gradient(
  90deg,
  red 40%,
  white 40%,
  white 60%,
  blue 60%
);
```

### 1.5 重复渐变

repeating-linear-gradient()函数和函数 linear-gradient 的效果基本相同，唯一的区别就是前者会重复。对于重复渐变，最好使用特定的长度而不是百分比，因为设置的值决定了要重复的图片大小。

```css
background-image: repeating-linear-gradient(
  -45deg,
  #57b,
  #57b 10px,
  #148 10px,
  #148 20px
);
```

## 2 径向渐变

### 2.1 径向渐变示例

径向渐变是从一个点开始，全方位向外扩展，使用 radial-gradient 函数实现：

```css
// 由中心 #e66465 颜色向外发散为 #9198e5)
background: radial-gradient(#e66465, #9198e5);

// 发散部分鱼容器有相切效果
background: radial-gradient(closest-side, #3f87a6, #ebf8e1, #f69d3c);

// 正圆发散
background: radial-gradient(circle at 100%, #333, #333 50%, #eee 75%, #333 75%);

// 椭圆发散
background: radial-gradient(ellipse at top, #e66465, transparent);
            radial-gradient(ellipse at bottom, #4d9f0c, transparent);
```

默认情况下，渐变在元素中是从中心开始，平滑过渡到边缘。跟线性渐变一样，径向渐变同样支持颜色节点，可以提供多个节点，使用百分比或者长度单位指定节点位置。也可以把径向渐变设置为圆形而非椭圆，甚至可以指定渐变中心点的位置。

repeating-radial-gradient()函数可以重复生成图样，形成同心圆环。

### 2.2 锐利的径向渐变

和线性渐变一样，要设置锐利的径向渐变，也需要为同一个起始位置设置 2 个色彩值：

```css
background: radial-gradient(
  orangered 15%,
  orange 15%,
  orange 30%,
  gold 30%,
  gold 45%,
  lightgreen 45%,
  lightgreen 60%,
  cyan 60%
);
```

### 2.3 有透明度的径向渐变

和径向渐变类似，可以使用关键字 currentColor、transparent 替代色彩值。
