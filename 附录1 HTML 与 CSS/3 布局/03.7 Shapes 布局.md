# 7 Shapes 布局

与 float 配合后，使用 CSS Shapes布局可以实现不规则的图文环绕效果（不兼容 IE，旧版 Edge）。

## 7.1 shape-outside

shape-outside 支持的值有：

- `none`表示默认值，即普通的矩形环绕
- `<shape-box>`表示图形盒子，指定文字环绕时依照哪个盒子的边缘来计算，支持 `margin-box、border-box、padding-box、content-box`。
- `<basic-shape>`表示基本图形函数，与和clip-path剪裁属性支持的基本形状函数一样
- `<image>`表示图像类。包括URL链接图像、渐变图像、cross-fade()函数图像、element ()函数图像等。

```css
/* 关键字属性值 */
shape-outside: none;
shape-outside: margin-box;
shape-outside: padding-box;
shape-outside: border-box;
shape-outside: content-box;
/*
    形状函数值
    circle( [<shape-radius>]? [at <position>]? )   ?表示0或1，即shape-radius（圆半径）和position（圆心位置）都可以省略
    ellipse( [<shape-radius>{2}]? [at <position>])  <shape-radius>指水平半径和垂直半径，<position>指圆心
    inset( <shape-arg>{1,4} [round <border-radius>]? ) shape-arg必须，可以是1～4个值，分别表示以当前元素的4个边缘为起点，从顶部、右侧、底部和左侧向内偏移大小(支持类似 padding 那样缩写)
    polygon( x1 y1, x2 y2, x3 y3, ... )
*/
shape-outside: circle();    // 圆
shape-outside: circle(50%);
shape-outside: circle(at 50% 50%);
shape-outside: circle(50% at 50% 50%);
shape-outside: circle(50px at 50px 50px);

shape-outside: ellipse(); // 椭圆
shape-outside: ellipse();
shape-outside: ellipse(50px 75px);
shape-outside: ellipse(at 50% 50%);
shape-outside: ellipse(50px 75px at 50% 50%);
// 表示最长边的长度和最短边的长度，浮动元素25% 25%的位置作为原点，以距离浮动元素边缘最长的距离作为椭圆的 坐标，
// 以距离浮动元素边缘最短的距离作为椭圆的 坐标
shape-outside: ellipse(farthest-side closest-side at 25% 25%)

shape-outside: inset(10px 10px 10px 10px); // 内矩形

shape-outside: polygon(10px 10px, 20px 20px, 30px 30px); // 多边形
shape-outside: polygon(0 0, 0 100px, 100px 200px);
shape-outside: polygon(0 0, 100px 0, 0 50px, 100px 100px, 0 100px);

/* <url>值 */
shape-outside: url(image.png);
/* 渐变值 */
shape-outside: linear-gradient(45deg, rgba(255, 255, 255, 0) 150px, red 150px);
```

```html
<style>
  .shape {
    float: left;
    width: 60px;
    height: 60px;
    padding: 10px;
    margin: 10px;
    border: 10px solid;
    border-radius: 50%;
    background-color: currentColor;
    background-clip: content-box;
    color: #cd0000;
    shape-outside: none; /* margin-box、border-box、padding-box，content-box */
  }
</style>

<span class="shape"></span>
<p>文字内容文字内容......</p>
```

实现文字环绕一个不规则图：

```css
.shape {
  float: left;
  width: 200px;
  height: 300px;
  /* 文字环绕*/
  shape-outside: url(./birds.png);
  background-color: #cd0000;
  mask: url(./image.png) no-repeat;
}
```

## 7.2 shape-margin

shape-margin 可以控制文字环绕图形时文字与元素边界的距离。

shape-margin只支持1个属性值，有效数值范围是从0到浮动元素的边界，当shape-margin的属性值超过浮动元素边界的时候，布局效果如同普通浮动布局效果，没有不规则的图形环绕效果。

## 7.3 shape-image-threshold

shape-image-threshold指图像环绕时候的半透明阈值，默认是0.0，也就是图像透明度为0的区域边界才能被文字环绕。同理，如果属性值是0.5，则表示透明度小于0.5的区域都可以被文字环绕。
