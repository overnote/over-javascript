# CSS 规则&变量&属性&类型

## 1 规则

CSS 规则以@符号开头，常用的有：

- @import：在当前样式表中导入另一个 CSS 文件。
- @font-face：定义并加载自定义字体，让页面可以使用指定字体文件。
- @keyframes：定义动画的关键帧序列，供 animation 使用。
- @media：根据媒体查询条件（如屏幕宽度、打印、偏好设置）有条件地应用样式。
- @page：定义分页媒体（主要是打印）中页面盒子样式，如页边距、纸张尺寸。
- @supports：检测浏览器是否支持某条 CSS 声明，支持时才应用对应样式块。

已经不常用或者废弃的还有：

- @namespace：为样式表声明 XML 命名空间，常用于 SVG/XML 文档。
- @charset：声明样式表使用的字符编码，且必须放在文件最开头。
- @document：按文档 URL 条件应用样式，但它是非标准规则且已废弃。

## 2 CSS变量

### 2.1 变量定义

```css
:root {
  --primary-color: deepskyblue;
}
button {
  background-color: var(--primary-color); // 可以添加第二个值，作为默认值
}
```

CSS 的变量支持使用短横线和空格命名，但不可以使用数字进行命名。使用 `$、[、]、^、(、)、%、"`等特殊字符的命名时，需要使用反斜杠转义。

### 2.2 全局变量

`:root` 伪类可以看作一个全局作用域，在内部声明的变量，所有的选择器都可以拿到。

而在 `.box` 等中定义的变量则为局部变量。

## 3 CSS 属性与类型

css 由 属性+类型值决定显示结果，如：

```css
background-image: none | <image>;
mask-image: none | <image> | <mask-source>;
```

这里 background-image 是属性，而这个属性拥有很多类型值：`<url> 、<gradient>、element()、image()、image-set()、cross-fade()` 等。

常见的类型值有：

- `<image>`：`<url>`、`<gradient>`、element()、image()、image-set()、cross-fade()、paint()
- `<box>`:content-box、border-box、padding-box
- `<shape-box>`: `<box>`、margin-box
- `<basic-shape>`:inset()、circle()、ellipse()、polygon()、path()

属性值语法，以 `linear-gradient( [ <angle> | to <side-or-corner> ,]? <color-stop-list> )` 为例，包含三部分

- 关键字：to、auto、none、ease、inherit、initial、unset、revert
- 数据类型： 被 `<>` 包裹的，`<angle>、<side-or-corner>和<color-stop-list>`
- 符号：
  - `,`：分隔数个并列值或者函数参数值
  - `/`：分隔一个值的多个部分，在缩写中用于分离类型相同但属于不同 CSS 属性的值
  - 表示出现次数的数量符号：
    - `*`：可出现任意次数
    - `+`：可出现一次或者多次
    - `?`：可出现零次、一次，即可选
    - `{A,B}`：最少出现 A 次，最多出现 B 次
    - `#`：可出现一次、多次、但多次出现必须逗号分隔
    - `!`：当前分组必须产生一个值
  - 表示元素关系的组合符号：
    - `&&`：与符号，各部分必须出现
    - `||`：或符号，各部分至少出现一个
    - `|`：互斥符号，各部分只能出现一个
    - `[]`：优先级，其实就是数学运算中的小括号 `()`，css 中 小括号表示函数，则改用 中括号表示
